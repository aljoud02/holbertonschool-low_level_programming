# 0x0A. C - argc, argv

## Description
This project focuses on understanding and manipulating command-line arguments in C using `argc` and `argv`, along with handling unused parameters using compiler attributes.

## Requirements
* **OS:** Ubuntu 20.04 LTS
* **Compiler:** `gcc` with `-Wall -Werror -Wextra -pedantic -std=gnu89`
* **Style:** Betty coding and documentation standards

## Tasks
* **0-whatsmyname.c:** A program that prints its name, followed by a new line.
